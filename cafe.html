Cafe and Resto (Bite 'n Brew) Web User Interface

Bite 'n Brew was developed as part of my mini project for the frontend web development bootcamp at Dibimbing.id.
Below is a brief overview of the project.

In this project, I manually created a static web user interface using HTML, CSS, Tailwind CSS, and a bit of JavaScript without relying on any templates. Rather than slicing a Figma design, I spontaneously implemented my ideas and translated them directly into a web-based interface. I applied a mobile-first approach by utilizing Tailwind's breakpoints, ensuring the design is fully responsive across various devices, including desktops, tablets, and mobile phones. The website consists of five pages: home page, menu page, about us page, contact us page, gallery page, and reservation form page.
